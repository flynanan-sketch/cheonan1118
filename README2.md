# 맛있는 여행, 천안 — 웹 프레젠테이션

원본 `cheonan_food_tour_final(1).pptx`의 10장 슬라이드를 그대로 보존한 GitHub Pages용 정적 웹사이트입니다.

## GitHub Pages 게시

1. 이 ZIP을 풀어 **파일과 `assets/` 폴더를 함께** GitHub 저장소의 최상위 경로에 업로드합니다. (ZIP 파일 자체를 업로드하지 마세요.)
2. 저장소의 **Settings → Pages → Build and deployment**로 이동합니다.
3. Source를 **Deploy from a branch**, Branch를 **main**, Folder를 **/(root)**로 선택하고 Save합니다.
4. 게시된 URL `https://사용자명.github.io/저장소명/`으로 접속합니다.

별도 서버, 빌드, 데이터베이스, API 키가 필요 없습니다. `index.html`을 직접 열어서 로컬 확인도 가능합니다.

## 조작

- 상단 **목차**와 하단 썸네일로 이동
- **← / →** 및 **PageUp / PageDown** 키로 이동, **Home / End**로 첫/끝 이동
- 화면 좌우 스와이프 또는 슬라이드 위 스크롤로 이동
- 자동 재생 / 전체 화면 / 원본 텍스트 및 참고 출처 확인
- URL 끝에 `#slide-5`를 붙여 특정 슬라이드 공유

## 폴더

- `index.html` — 사이트 시작 페이지
- `styles.css` — 반응형 스타일, 애니메이션
- `app.js` — 탐색, 단축키, 터치, 자동 재생
- `slides-data.js` — 10개 슬라이드 텍스트/원본 참고 출처
- `assets/slides/` — 원본 슬라이드를 고화질 WEBP로 변환한 이미지

## 원본 충실도와 주의사항

시각적 충실도를 위해 각 슬라이드는 고해상도 이미지로 표시합니다. 텍스트를 검색/복사하거나 링크를 열려면 **상세 정보** 패널을 이용하세요. 별도의 차트 데이터나 편집 가능한 PPT 도형은 웹 요소로 재구성하지 않았습니다. 원본 자료의 합성 홍보 이미지와 AI 생성 음식 이미지는 실제 매장 사진이 아닙니다. 매장 정보는 방문 전 확인하세요.

Google Fonts가 차단되어도 시스템 폰트로 정상 작동하며, 이미지 등 필수 리소스는 저장소 내부에 들어 있습니다.
